# 🧮 Simple Calculator

A simple and responsive calculator web application built using **HTML, CSS, and JavaScript**. The project provides a clean interface for performing basic arithmetic calculations.

## 📌 About the Project

This calculator is a beginner-friendly web development project designed to demonstrate the use of **HTML for structure, CSS for styling, and JavaScript for functionality**.

It supports basic mathematical operations through an easy-to-use interactive interface.

## ✨ Features

* Addition, subtraction, multiplication, and division
* Decimal number calculations
* Clear (`AC`) functionality
* Delete (`DEL`) functionality
* Parentheses support
* Responsive and user-friendly interface
* Keyboard input support
* Clean and modern design

## 🛠️ Technologies Used

* **HTML5** – Structure of the calculator
* **CSS3** – Styling and responsive layout
* **JavaScript** – Calculator logic and user interaction
